# 图片面板内的独立生图 API

本轮交付是代码和静态核对，尚未进行配置保存、界面、图片生成、重绘或真实服务验证。用户 DSH 当前加载的代码版本未知。

入口：图片生成与处理 → 生图 API 设置。

- **独立生图 API**：填写协议、基础地址和密钥；Gemini 或 OpenAI/GPT Image 兼容协议可选填模型 ID。留空时沿用现有目录读取代码；手动 ID 明确标记为用户配置、未核验，不冒充服务目录。
- **复用 DSH 已有连接**：保留原有 DSH 图片服务及独立 API 配置，之后可以切回。
- 保存配置不会调用模型目录或生成服务；返回图片面板时才按当前配置读取目录（手动指定模型时不读取目录）。实际生成仍由用户主动提交。
- 地址或协议改变后必须重新输入密钥；只改模型可以保留已有密钥。清除独立配置会切回 DSH 连接，并尝试清除独立密钥；清理失败有单独提示。

OpenAI 兼容选项沿用 GPT Image JSON 生成、multipart 参考编辑和 base64 图片返回协议；不代表任意名为“OpenAI 兼容”的服务都支持这一协议。自定义地址及手动模型不会继承 OpenAI 官方地址的透明背景、尺寸、画质或 SVG 能力标记。手动模型的参考图能力只按协议及名称保守推断，实际支持由服务返回决定。OpenRouter、Venice 仍使用对应官方地址和实际目录。

## 存储与权限

Host 从当前 DSH `settings.documentPath` 获取用户/profile目录，在其 `designcraft/image-api.json` 保存非秘密元数据。密钥以独立 `DESIGNCRAFT_IMAGE_API_<随机身份>` 引用交给 DSH `credentials.set` 保存，每次操作通过 `resolve` 读取；采用 DSH 自身的存储和访问策略，本功能不另外承诺加密方式。密钥只在配置提交方向进入 Host，读取接口不返回密钥，也不写浏览器存储、作品、任务或项目导出包。

配置接口复用 DSH owner admission、同源检查和设计 view capability/epoch 检查。支持配置版本冲突检查、跨进程写锁及元数据原子替换；先保存新密钥引用，再提交元数据，失败清理或旧引用清理异常会提示。配置切换清除模型缓存，独立配置的版本参与连接摘要；已有未确认请求不会因保存设置而自动重发。设置存储不可用时，既有 DSH 模式仍可使用，设置界面明确提示不可保存；配置文件损坏则明确报错，不自动覆盖。

## 默认界面范围

图片面板保留生成、选区重绘、在线找图、生图 API 设置。PixelBin、fal、产品图和外部工作流放入“更多服务”；Venice 放大/移除背景从这里显式选择。网页面板的 Stitch、Figma MCP 也放入“更多服务”。原有代码、任务和用户连接数据保留，额外平台不是核心产品的前置条件。原版 OD/Vela 图库退出本轮必做范围；Commons 仍是独立的可选真实图片来源。

待用户通知后再验证：密钥服务可写与保存重读、跨窗口冲突、切换/清除、服务目录及生成、参考图与重绘、实际界面及原作品保护。语法和静态源代码核对不等同这些功能已经通过。

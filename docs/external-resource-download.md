# 外部原包文件下载（代码阶段）

网页工作区的外部原包面板可在用户选中实际文件后请求下载，包括 PDF、文字和其他原包文件。操作先沿用已有的原件保存和来源登记：普通文件与已保存原包的 Git 对象及 SHA-256 核对；LFS 指针必须取得并核对真实文件，不会把指针当成实际文件。选择 LFS 文件并点击下载可能联网，实际文件上限为 16 MiB。

专用下载接口使用当前视图和工作区身份，再次核对原包、来源回执及已保存字节；返回内容作为不可直接执行的附件。界面收到后再核对文件身份、字节数及 SHA-256，仅发出浏览器下载请求。文件名中系统不允许的字符会被替换。操作不会自动运行文件、启动外部应用或修改原网页，原包与项目素材保留。

单独分享原文件时，应同时保留适用的许可与署名；单文件下载不会自动打包许可。PDF 文件是否能打开、浏览器是否完成保存及外部素材的具体使用权仍需核对。此路径目前只完成代码和静态检查，尚未运行文件下载、LFS、浏览器、项目包或界面验证。

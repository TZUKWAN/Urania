# 已保存网页的外部依赖候选

网页工作区的“检查已保存版本的外部依赖”和 `designcraft_html dependencies` 只读取指定保存版本的 HTML/CSS，列出常见静态写法中的外部脚本、链接资源、媒体和 CSS 资源来源。结果只显示协议、主机和端口，不返回 URL 路径、查询参数或凭据；检查不会联网，也不会修改网页或本地草稿。

这是有文件、字节、匹配数及结果数量上限的启发式检查，不是 HTML/CSS 完整解析器或安全审计。注释、脚本字符串可能造成误报，动态拼接、编码、未支持的语法和超出预算的内容可能遗漏；检查结果为空不证明网页没有外部依赖。预览对外链有隔离限制，Tailwind 和字体等依赖仍需实际处理，候选列表不证明资源已加载或页面外观正确。

此入口仅完成代码和静态检查，尚未运行功能、界面或实际模板验证。

# 设计意见、原生保护与固定版本输出

本轮版本：`1.3.0-dev.149 / UI164`。沿用 DSH 项目独立设计对话与 Vector19、Photo8、Deck18；动画继续使用可编辑 HTML/CSS/JS 工程。没有安装 Planners Skill/Python 工作台，也没有恢复已取消的采集功能或已放弃的外部服务。

## 用户操作

- 选中对象、Shift 加选或使用原生图片区域，在浮框写修改要求。默认“发送给 AI”；“暂存意见”只保存，不调用模型。没有选中对象时，“让 AI 修改”针对当前页。
- 输入按项目、源、真实页 UID 和对象分别保存。切换页面、作品和重新加载后可以恢复。浏览器保存紧急副本，宿主以版本比较保存耐久草稿；遇到另一窗口的修改会保留冲突两份供选择。
- 展开“设计意见”查看队列、合并多页要求或核对回执。“模板与版式参考”将文字要求保存为 AI 任务；只有实际原生修改并保存后才显示修改结果。
- 合并意见和诊断在输入框显示为简洁引用卡片，内部目标与任务合同不展开占用草稿；真正发送时由 DSH 注册序列化器保留完整上下文。
- 主对话有草稿、引用或附件时，意见先合并进去，等待用户发送。相同批次只预约一次送达；未确认的发送不会自动重复。新一轮相同文字拥有新的动作和批次身份。
- “意见已保存”来自实盘记录；“AI 已收到”来自模型实际调用读取工具；“修改已保存”要求匹配本批次的真实原生动作、目标对象/页面变化和源检查点。模型的文字答复不构成完成证据。
- PPTX 导出先保存并固定原生源版本，再核对实际文件的页序、可编辑文字、内嵌资源和 SHA256。文件和回执保存在项目的 `design/.designcraft/exports/<导出身份>/`；导出提示可另存 JSON 回执。继续编辑后，旧回执标记为先前版本。未进行渲染复核会明确显示未执行。
- “更多操作 → 设计诊断与帮助”读取版本、编辑器状态和脱敏错误，可自行复制或交给当前设计 AI。不会自动外发，不包含普通对话、服务配置、密钥或本地路径。

## 原生编辑与任务合同

`designcraft_feedback read` 先读取持久任务、当前版本和人工保护字段。每次原生 `execute` 都携带该批次 `feedbackId` 以及最新 `sourceId / epoch / base`。定位使用真实 UID，页码只用于显示；切换后重新读取状态。

宿主将候选与真正保存的完整原生源对照。非目标对象、其他页面和后来的人工字段受到保护；整页/模板任务不默认解除人工保护。用户针对某个对象提出当前要求时才放开该对象；早先排队的要求不覆盖之后的手改。保护文件只记录修订游标、字段路径和摘要，原生源仍是唯一设计权威。图片真实像素覆盖继续由原生选区合同控制，不把平面图片描述成独立语义对象。

未通过核对的候选会进入隔离草稿，宿主阻止该视图的后续自动保存，并耐久记录被拒内容摘要。重新加载仍不能把该候选恢复到原稿。“保留候选并返回原稿”先保存独立原生作品，再重新打开未覆盖的原稿；也可只选择恢复为独立设计。隔离与恢复经过真实原生动作、自动保存等待和实际重载验证。新增的 `feedback-edit` 源回执绑定批次与原生动作，只接受 AI 保存来源和有效的现有基线。

`complete` 使用本批次实际保存的 `jobIds` 核对真正发生变化的 UID/页、人工字段检查、时序和检查点。定位、选择、无内容变化、未保存或其他会话动作不能冒充修改。证据进入耐久动作记录，重启后仍可核对；新批次不复用旧完成状态。

## 动画权限与时钟

所有动画 HTTP 操作沿用宿主 owner 与 Origin 验证，并解析真实的项目设计会话。旧的 DSH 同源生成 HTML 地址返回失效状态。新预览在不同 loopback hostname，使用精确修订的只读、限时、可撤销票据；生成代码位于仅允许 scripts 的不透明 iframe。可信外层只传播放、暂停、定位、就绪、时间和选择消息，核对 Window 来源、origin、随机 nonce 与视图代际；没有写文件或发聊天消息的桥。

实际验证覆盖本地字体/图片、前后定位、消息伪造、跨源 DOM/Cookie/storage/HTTP/导航拒绝和隐藏工作区撤销。该边界不等于操作系统虚拟机，也不声称防止任意脚本的资源耗尽或所有浏览器通道。

预览与渲染现在共用帧时钟，按子场景在父场景中的偏移推进；产品模板保留八个原始场景时间段。渲染使用任务独立的无窗口浏览器配置，额外需要 Node 22+、可用 Chromium 和 FFmpeg；本轮实际环境 Node 25.6.0。没有下载新依赖或改动用户浏览器配置。

导出浏览器也通过工程内只读 HTTP 获取资源，并施加不透明 sandbox、CSP 和实际 CDP 请求拦截，不直接打开磁盘 HTML。只允许本工程页面和资源；data/blob 只作资源，不允许用作页面跳转。FFmpeg 音频文件校验本工程真实路径并限制输入协议。实际敌意导航验收为零外部请求、退出码 1、没有伪产物；正常四轨音频模板也已重新导出通过。

# Tailwind 兼容预览

网页面板可主动勾选“Tailwind 兼容预览”，再刷新预览或转换演示；`designcraft_html convert` 可显式传 `tailwindCompat=true`。默认关闭。启用时宿主只向 `https://cdn.tailwindcss.com/3.4.17` 请求官方 Play CDN 脚本，不发送网页内容或项目凭据；脚本需满足固定字节数和 SHA-256，随后仅放在当前预览的临时能力范围中，并在现有隔离 iframe 里加载。预览本身不写回网页源文件。

兼容替换只接受入口中唯一一个无额外属性或插件参数的常见官方 CDN 脚本标签；匹配规则是文本启发式，可能误认注释或遗漏其他写法。脚本加载失败或没有观察到固定版本的样式标记时会提示并停止该预览；观察到标记并不证明所有类、动画或视觉效果正确。Google Fonts 等其他外链依赖仍未自动接入。

Tailwind 官方将 Play CDN 定位为开发预览；此选项不是生产 CSS 构建。仅预览或转换时，原网页和导出的 ZIP 仍保留原有外链。转换时尝试捕获当前预览状态，并在本次转换提示中注明兼容模式。服务端核对预览文件与已保存网页版本一致且临时脚本曾被请求后，会把固定版本与摘要写入新的转换回执；样式标记仍是客户端报告，并不独立证明脚本执行或视觉正确。若同一网页版本和相同 PPTX 摘要已有不同来源回执，保留原回执并提示本次来源信息未覆盖；字体、布局和 PPT 可编辑性仍需实际检查。

在网页面板主动启用兼容预览后，可选择“保存当前静态样式”；当前对话也可按用户明确要求调用 `designcraft_html freeze_tailwind`，传网页 `id`、保存的 `revision` 和稳定 `operationKey`。此动作在隔离预览中读取客户端报告的唯一 Tailwind 3.4.17 样式，将其作为 CSS 文件和官方 MIT 许可原文一起保存到同一网页的新版本，并将入口内唯一受支持的 CDN 脚本标签改为本地样式表链接。原版本保留；遇到入口含 `base`、路径冲突或保存基线改变时拒绝覆盖。新版本中的该 CSS 可随网页 ZIP 导出，但仅反映当次预览报告的样式，不能保证动态类、Google Fonts、其他外链或视觉效果离线可用。服务端验证原文件摘要、脚本请求与 CSS 字节摘要，不能独立证明 CSS 由该脚本生成或内容完整。结果不确定时，用同一 `id`、基础 `revision` 和 `operationKey` 调用 `freeze_tailwind_status` 核对；面板保留待核对身份，避免直接重复提交。

对于已经登记的项目字体，可另按实际需要加入网页并手动引用，见 `docs/html-project-fonts.md`；这不等于自动替换所有外部字体，也不证明许可或视觉效果。

原模板的无版本 CDN 标签本身没有固定其历史版本；这里选择 3.4.17 作为兼容尝试，不证明与上游创作时使用的版本一致。固定 SHA-256 为 `176e894661aa9cdc9a5cba6c720044cbbf7b8bd80d1c9a142a7c24b1b6c50d15`，来自本次官方 HTTPS 读取，不是上游签名。脚本变更、网络不可用或隔离策略不兼容时会拒绝该模式；可关闭选项继续处理原稿。

此功能只完成代码、公开来源摘要与静态检查；尚未在产品中下载或运行脚本，也没有进行预览、保存、转换、UI、项目包或视觉验证。官方说明：[Tailwind v3 Play CDN](https://v3.tailwindcss.com/docs/upgrade-guide)。

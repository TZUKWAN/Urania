# UI165 界面审计

基线 de6c3fb / 1.3.0-dev.150，在 Windows 的独立 DSH 0.2.2-rc.1 和真实 Chromium 中加载上一次交付包。用同一个矢量海报、分层图片、三页演示和一个代码动画记录 1280×720、1440×900、1920×1080。原始截图与矩形测量在本地验收目录的 evidence/before，未读取用户会话。

| 实测画面 | 问题 | 修改目标 |
| --- | --- | --- |
| 01 首页、02 输入 | DSH 外侧导航、对话、空白画布都是近白；只有空白矢量和导入两种明显入口。动画按钮独占一行。对话选中说明与画布工具条重复 | 一行共享导航，四类入口、历史入口和可收纳 AI 对话 |
| 03 新建 | 顶栏直接创建默认作品，与自定义尺寸表单的路径断开 | 从同一个类型选择和尺寸表单开始，保留一键空白画板 |
| 04 矢量 | 画布上方分开排列工程状态、选区说明、意见列表；缩小窗口后有效画布窄 | 画布占优、短标签呈现选区、可收起附属工具 |
| 05 导出、06 作品、07 素材 | 打开菜单时底层原生画面暂停并隐去；菜单看起来像整页按钮带，状态和关闭路径不一致 | 保留真实暂停与保存边界，使用定位浮层、缩略图、来源和清楚的焦点 |
| 08 Photo、09 Deck | 图片工具和幻灯片缩略图属于原生 WASM。外层同类按钮的位置不一致。缺字体提示在测试演示确实出现 | 保留原生交互，在外层统一选区工具、工作区身份和可操作反馈 |
| 10 Motion | 播放条只有粗略秒数，帧率、当前帧、选区、渲染回执与后续动作没有稳定位置 | 真正的时间标尺、可拖动播放头、实际帧/片段、渲染状态及成品入口 |

功能边界经实际代码核对。设计对话由 DSH SessionProvider 绑定专用会话。画布是独立来源 iframe，选区使用真实对象、页、修订和租约。暂停面板会先保存及移除跨来源命中区域；不能用视觉调整绕过这些约束。Photo、Vector、Deck 精细工具维持原生编辑器，Motion 预览仍使用无特权独立来源。

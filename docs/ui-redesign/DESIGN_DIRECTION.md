# 视觉方向

Lovart 的首页、创作指南和 Canvas 文档把开始创作、项目列表和素材分开。选中对象之后才出现具体操作，Quick Edit 随选区出现，图层也可以按需弹出。Urania 采纳这种按需出现的结构，保留已有专用设计对话及原生编辑。 [Lovart 首页](https://www.lovart.ai/) · [首次创作](https://www.lovart.ai/docs/getting-started/design-your-first-project) · [画布交互](https://www.lovart.ai/docs/edit-your-design/customize-your-canvas)

Figma 的属性面板随所选对象呈现对应属性。Framer 将动效与系统减少动态效果联动。Linear 用重复的标题、导航和状态规则降低切换成本。Raycast 为短操作提供键盘途径。 [Figma 属性面板](https://help.figma.com/hc/en-us/articles/360039832014-Design-prototype-and-explore-layer-properties-in-the-right-sidebar) · [Framer 减少动态效果](https://www.framer.com/help/articles/reduced-motion-settings/) · [Linear 界面更新](https://linear.app/changelog/2026-03-12-ui-refresh) · [Raycast](https://www.raycast.com/)

| 可落地方向 | 收益 | 取舍 |
| --- | --- | --- |
| 暖白创作台 | 暖灰工作面、浅紫选区与细边框，让页面和图片成为视觉中心。清楚区别对话、操作条和画布 | 需逐个核对原生画布的浅色边框与白色作品分离度 |
| 冷灰专业台 | 蓝灰分区和密排工具在高密度多对象作业中稳定 | 在 1280 窗口中三栏容易拥挤，容易恢复成传统工程面板 |
| 石墨影院 | 深色环境适合影像、颜色比对和动画监看 | 首次创作和长文字阅读偏重，也容易与宿主深色层混合 |

采用第一方向，暗色沿用宿主偏好并配套石墨色。品牌视觉以 Urania 的星轨图形、墨色文字和低占比紫蓝强调为主。主舞台与辅助界面之间由背景明度、间距和对齐组织。选区工具保留真实坐标和即时反馈，只有界面层使用短过渡。

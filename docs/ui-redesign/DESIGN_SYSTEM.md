# Urania 工作台设计规范

工作台采用 4px 间距单位，以 8、12、16、24、32px 组织相邻控件、组内内容和区块。导航及文件栏的常态高度为 49px，主要控件高 34px。面板与图标可在窄窗口缩成紧凑模式，按钮保留名称和原生提示。分隔线传达具体层次，组件之间优先用间距和对齐。样式和图标集中在 client/studio-system.js。

| 语义 | 暖白 | 石墨 | 使用范围 |
| --- | --- | --- | --- |
| 工作面 / 面板 / 浮层 | #f0eeeb / #fcfbf9 / #fffefd | #201f24 / #29282e / #313038 | 画布外层、对话和工具栏、浮动面板 |
| 主文字 / 次文字 / 辅助 | #24232a / #494750 / #65616d | #f0edf3 / #d2cdd9 / #b0aab9 | 标题、控件、日期与解释 |
| 分隔线 / 选中背景 | #e3dfdc / #eeebfa | #433f49 / #403751 | 框和规则线、当前对象与选中工具 |
| 品牌 / 品牌上文字 | #5847a1 / #ffffff | #baaef7 / #232031 | 星轨、AI、主操作、指示 |
| 成功 / 警告 / 错误 | #307245 / #855d18 / #a23643 | #9fd6aa / #ebca8b / #ffadba | 和可读状态名或图标一同出现 |

文字使用系统 Segoe UI Variable、Segoe UI、Microsoft YaHei UI，随后回退到 PingFang SC 与系统无衬线字体。这样中英文离线可读。首页标题 27–43px，产品标题 16px，面板标题 15px，工作标题和正文 13px，控件 12px，辅助 11–12px。时间和帧数采用等宽数字。8px 圆角用于控件，14px 用于卡组，18px 用于浮层。阴影集中于浮层和较大的真实作品预览。

导入、撤销、作品、素材、属性、导出、AI、播放等界面图标使用本项目绘制的 24px 网格和统一线宽。图片、矢量、演示、动画用独立的小型浅色标识。装饰星轨只出现在首次创作，原生作品和预览仍占主位。

| 组件 | 默认与交互状态 |
| --- | --- |
| 按钮、操作条、分段 | 克制底色；悬浮、按下、禁用、选中与焦点各有独立反馈；图标按钮有可访问名称 |
| 输入、选择器、引用与附件 | 亮边、键盘可见聚焦；DSH 原生输入管理多行、附件、模型和发送；作品目标单独显示短标签 |
| 浮层、历史、素材与属性 | 独立背景、可滚动内容、关闭动作、空态、加载和错误；打开作品沿用真实快照与校验 |
| 提示、回执与进度 | 文字和图标表达真实任务；仅在实际任务有数值时显示进度条；错误提示优先提供可恢复操作 |
| 时间轴 | 秒标尺、实际帧、轨道、组件时段；Web Animations 可观察的关键帧显示为菱形；拖动或键盘精确跳帧 |

动效使用 135ms 反馈、180ms 菜单和提示、245ms 面板、290ms 页面，常用曲线 cubic-bezier(.2,.8,.2,1)。菜单和对话采用轻微位移或缩放与透明度变化，拖动宽度按一帧一次提交给浏览器布局，原生对象操作即时。系统减少动态效果关闭非必要的位移、播放头插值与骨架脉冲，保留当前状态。真实作业进度或滚动始终由相关引擎和任务控制。

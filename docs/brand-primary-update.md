# 项目品牌主色

品牌面板提供主色修改入口。当前品牌没有已启用的对象绑定时，提交会以项目关系的当前版本为基线，只修改该品牌主色并记录品牌事务；未绑定或已停用的作品对象不随之改变。已有启用绑定时，沿用原有成员核对、逐源保存和人工配色覆盖保护。 品牌主色更新结束后，仍确认旧主色的绑定会保持手工覆盖状态，直至按现有流程明确恢复并重新绑定；进行中的批量事务按原状态处理。

当前 DSH 会话可先用 `designcraft_editor brand_state` 读取项目版本和全部绑定，再用 `brand` 的 `recolor` 传完整的已启用 `bindingIds` 与实际手工覆盖 `overrideIds`。只有实际没有启用绑定时才传两个空数组；状态变化或成员不符会拒绝覆盖。响应不确定时先重新读取项目品牌状态。

该补充路径只完成代码和静态检查，尚未进行功能、界面、并发冲突或项目包验证。

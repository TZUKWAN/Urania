# OpenDesign 品牌视觉板指导接入（代码阶段）

固定 OpenDesign 提交中的 `skills/brandkit/SKILL.md` 不只是外部目录链接，文件本身包含品牌策略、标识构思、视觉板排版、色彩和提示词指导。`designcraft_resources` 的 `read` 按固定 Git blob 核对并返回真实原文，超过分页时须继续读取；原文件来源可用 `designcraft_plan` 的 `resources` 明确记录。固定仓库许可及其他素材的实际许可仍须按来源核对。

当用户要求品牌视觉板时，当前 DSH 对话可结合真实用户需求和这份原文起草设计计划及提示词，按用户需求使用 `designcraft_image_studio` 选择实际配置的图片服务、模型和选项。图片任务受现有身份、取消和结果核对约束；不自动执行上游代码、安装额外软件或启动另一套 agent。

计划中的来源只是声明，不独立证明模型读取或遵循；图片任务尚不直接关联计划。用户将图片候选打开并保存为原生作品后，才可通过现有计划关联入口对精确作品版本声明关联。生成的品牌视觉板是位图；图中文字、标识或模型预览不等于独立可编辑矢量，也不证明商标权、设计质量、可读性或字体许可。

本次只连接同会话的规则、计划和现有图片服务使用路径，未调用模型或图片服务，未做功能、界面、视觉、恢复或项目包验证。服务、额度和效果以实际使用时的结果为准。

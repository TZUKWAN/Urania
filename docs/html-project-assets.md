# 当前项目素材加入网页

`designcraft_html project_assets` 或网页工作区“项目素材”仅搜索当前 DesignCraft 项目图谱中的已保存 PNG/SVG 派生物；它不是原 OpenDesign 的全局素材库。列表只展示保存的元数据，加入前会读取并核对实际原生源版本与派生字节。

`apply_asset` 使用网页 `id`、精确保存 `revision`、实际 `assetId` 和稳定 `operationKey`。代码先核对项目关系历史、素材原件和网页基础版本，然后按 `assets/<素材摘要>.<格式>` 将原字节添加到新的 HTML 版本；同路径若存在不同内容会拒绝覆盖。网页入口、标题、原始来源及其他文件保持不变；不会自动插入 `<img>` 或修改正文。返回的相对路径可由用户或当前 DSH 会话明确引用。文件是当时的静态快照，源素材后续更改不会自动同步。

`asset_status` 通过网页保存版本中的稳定操作回执核对一次加入，不因其他操作碰巧加入相同字节就误判；`asset_ops` 列表只检查预约结构，`asset_recover` 只恢复完整的本地预约。网页面板可在保存当前草稿后明确选择并加入素材，响应丢失时保留待核对身份；工作区或草稿变化时不会覆盖当前内容。项目包核对预约、项目关系历史、实际源、派生文件、网页基础/结果版本和导出期间变化。

素材遵守项目图谱现有 SVG/PNG 派生物上限 4 MiB，以及网页 256 个文件、单文件 8 MiB、总计 24 MiB 限制。若素材已从当前项目图谱移除、历史关系缺失或网页已被其他操作更新，系统明确拒绝或保持未确认。SVG 的后续显示受现有预览安全策略约束；加入文件不代表已显示、视觉正确或全局 OD 库可用。此路径尚未进行功能、界面、故障恢复或项目包验证。

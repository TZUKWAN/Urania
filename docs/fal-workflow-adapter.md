# fal 通用工作流（代码已写入，尚未功能验证）

`designcraft_fal_workflow` 是当前 DSH 对话内的通用 fal 协议入口，不启动额外 agent，也不自动执行 OpenDesign 外部脚本。`search` 查询实际目录；`inspect` 返回模型真实输入、输出 schema 和摘要；`start` 需要检查后的同一摘要、实际输入及稳定操作身份，并在发送前重新核对 schema。模型接口含有当前验证器不支持的约束时拒绝提交，不猜测参数。

项目素材通过 `assetRefs: [{"pointer":"/image_url","asset":"实际素材名"}]` 显式绑定到输入对象中的 `null` 或 `"@asset"` 字段。代码只接受可从文件头确认的常见图片、音频、视频、PDF 或 GLB 素材，总输入上限 32 MiB；模型是否接受该素材仍由其接口决定。任务记录保存输入摘要和素材摘要，不保存请求中的原始提示词、数据 URI、凭据或签名链接。

提交先写入本地不确定状态，服务返回有效 request_id 后写入任务记录。`list` 和 `status` 查看记录；`stop` 只停止本地等待；`recover` 查询同一个远端任务；`cancel_remote` 明确请求服务取消，运行中任务仍可能完成或计费。若进程在记录写入时中断，`pending` 可列出保留的临时记录；`restore_pending` 需要准确文件名与摘要，核对身份、已有结果和素材后保留原记录并恢复。没有可核对的 request_id，或发现多个不同 ID，均不会自动重新提交。

允许来源的真实媒体由宿主下载为项目不可变素材；其他链接不会自动访问，结果中的链接及疑似凭据会隐藏。任务、未发布记录、保留的原记录及实际输入输出素材会由项目打包代码处理；单个输出上限 64 MiB、一次最多 8 个文件并受项目包总大小限制。被截断的文本、未知媒体类型、无法读取的地址和过期结果均应如实说明，不等同于完整作品或已导入原生编辑器。

本次只写入代码并做语法检查；没有调用 fal 模型目录、工作流或队列，也没有进行功能、界面、失败恢复或项目包验证。通用入口不证明 OpenDesign 中每个 fal、Venice 或其他外部技能已接通，更不证明所选模型实际可用、免费、具备某种语义效果或适合生产使用。

官方接口：[模型目录](https://fal.ai/docs/platform-apis/v1/models)、[队列与取消](https://fal.ai/docs/documentation/model-apis/inference/queue)、[模型 schema 样例](https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=fal-ai/flux/dev)。

补充：用户明确要求保留可复用的远端文件地址时，`captureRemoteOutputs:true` 将允许来源的实际结果地址加密记录；`remoteOutputRefs` 可在同连接、同凭据的后续任务中按真实输出和输入指针绑定。无法下载或超过预算的文件仅标记为远端引用，不视为本地原件。原始文件与 64 MiB 下载限制仍适用；链接可能过期，DPAPI 跨用户不保证恢复。详见 `fal-remote-outputs.md`；该路径尚未功能验证。

图片工作区提供“fal 工作流”面板：用户主动搜索模型、读取实际 schema、填写输入和引用，再自行提交。面板可选择实际本地 ZIP 或可识别媒体，核对摘要后保存到当前项目；此动作本身不发送 fal。项目素材引用分别填写 `pointer` 和 `asset`，已有远端输出引用填写 `pointer`、来源 `jobId` 和 `outputPointer`；是否选用存储及捕获远端引用由用户明确勾选。任务列表、详情、本地候选、停止本地等待、取回同一请求和远端取消均由用户主动操作，上一操作未确认时不会自动重发。表单原始输入不会持久化，续接时需重新填写完全相同的内容；刷新或关闭面板会丢失当前表单。查询/提交可能涉及服务费用，模型输入限制、文件兼容与远端状态以实际服务为准。该面板、文件导入、任务恢复及服务调用均尚未功能验证。

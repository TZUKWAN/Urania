# 设计计划与已保存作品的版本关联

`designcraft_plan link` 可在明确需要时，将项目中已经发布的某个设计计划版本和某个已保存 Vector、Photo、Deck 或 HTML 作品版本关联。参数使用实际计划 `id`/`revision`、`sourceType`、`sourceId`、`sourceRevision` 和稳定 `operationKey`；缺失或未发布的版本不会被猜测。原生源先读取实际保存文件并核对 SHA-256，HTML 源核对已发布版本链。相同操作身份重试只返回一致记录；若身份已用于不同内容则拒绝覆盖。

设计计划面板可由用户主动将当前**已保存**原生作品版本与正在查看的已发布计划版本关联；画布上尚未保存的修改不属于该关联。`links` 或面板“查看关联作品”分页展示记录，列表只检查记录结构；`verify_link` 或“核对版本”进一步读取并核对实际计划及作品原件。作品或计划后续编辑会产生新版本，不会自动改变既有关系。

`unlink` 或“停用关联”写入不可变停用记录，保留计划、作品和原关系；需要重新声明时可再次明确关联，使用新的操作身份。`recover_link` 只恢复已经完整写入且符合来源的本地临时候选，不重放作品编辑。项目包核对关系、双方实际保存版本、撤销记录与导出期间变化。某一历史计划或作品缺失时不能把该关系当作有效证据，打包会明确失败。

该关联是用户或当前 DSH 会话作出的声明，不独立证明模型实际读取或遵循了计划，也不证明视觉效果正确或功能验证通过。当前代码尚未经过功能、界面、恢复和项目包验证。

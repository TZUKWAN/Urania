# OpenDesign 外部原包 HTML 导入（代码阶段）

`designcraft_html from_external` 和网页资源面板可从已保存并校验的外部技能原包中选择实际 HTML 入口，创建独立的版本化网页源。用户可选择整个已保存原包，或只选择入口所在目录；原始文件路径和内容按保存的 Git 对象核对。需要预先通过 `designcraft_resources external_discover`、`external_inspect`、`external_fetch` 保存对应原包。默认只读取本地已保存的原包；仅在用户明确勾选「获取范围内 LFS 实际文件」或传入 `includeLfs=true` 时，才按原包中固定版本的 LFS 指针复用已保存文件或通过受限 GitHub 入口获取文件，并核对大小及 SHA-256。主机进程不执行原包脚本。

入口必须是有效且受支持的 HTML 文件。LFS 指针不会被当作实际文件；未选择获取时将其列为遗漏，选择获取后空文件或超限文件仍会列为遗漏，所需实际文件不可获取或校验不符时导入失败。范围外、不可移植路径、冲突路径、不受支持的 Git 文件类型和单文件超限项也按实际情况列入遗漏清单。入口自身被排除或所选范围超过 256 个文件、单文件 8 MiB、总量 24 MiB 的网页预算时拒绝导入，原包保持不变；失败前已核对并保存的 LFS 文件及回执可能保留供后续使用。服务返回遗漏总数和最多 50 条清理后的路径/原因；资源面板可查看这些信息。目录外依赖、外部 CDN、远端字体和构建工具不会被自动补造。

导入使用稳定 `operationKey` 创建独立网页身份；`external_status` 只查询该身份的本地保存状态，不重复创建，查询时须使用相同入口、范围和 LFS 选项。重用同一操作时会重新核对初始版本与原包，保留用户后续编辑；如果保存期间响应丢失，可使用原操作身份查询。网页面板保留上次未确认身份，允许核对或由用户明确停止等待。项目包核对初始网页文件、入口、原包摘要与选择/遗漏记录，以及所用 LFS 实际文件及其指针来源，并保留原包及其许可文件；后续用户编辑作为独立网页版本保留。原先默认不获取 LFS 的来源记录继续使用原有版本和摘要规则。

后续网页预览沿用现有隔离 iframe 和 CSP：页面脚本可在该预览沙箱中运行，不能将“主机不执行原包脚本”误解为预览完全无脚本。外部网络资源通常不会自动加载；具体交互、字体、视觉效果和 HTML 转 PPTX 的可编辑性/保真仍需实际验证。单独导出网页时，所有适用许可、署名和第三方素材权利仍需按原包核对。

本轮只编写代码并做静态检查；没有下载原包/LFS、打开网页、执行预览、转换 PPT、运行功能/UI/恢复/项目包验证，也没有操作或重启用户 DSH。

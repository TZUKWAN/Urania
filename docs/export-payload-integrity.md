# 导出前的载荷检查

网页 ZIP 导出会针对选定的已保存网页版本生成归档，响应附带源版本和服务端计算的 SHA-256。客户端下载前检查非空、ZIP 文件头、版本和字节摘要；摘要不一致或工作区已经切换时拒绝发起下载。

项目 ZIP 下载前检查非空和 ZIP 文件头；原生图片、矢量与演示导出检查返回的字节非空。项目 ZIP 的简单检查不是完整 ZIP 校验，原生文件非空也不证明其格式、内容或视觉正确。浏览器发起下载不等于文件已成功写入用户选择的位置；实际文件大小、打开和内容仍需在用户允许后验证。

本路径依据 OpenDesign 固定资源 `skills/export-download-debugging` 对“先确认导出载荷”的建议补充；目前仅完成代码与静态检查，尚未运行真实导出、下载、项目包、打开文件或界面验证。

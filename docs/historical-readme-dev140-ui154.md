DesignCraft 1.2 · DSH 统一设计工作区（UI16，历史资料）

在一个 DSH 工作区中使用同一套作品、页面、素材和版本。左侧沿用 DSH 原生对话、模型、审批和停止；中央共同画布负责手工编辑；PhotoCraft、VectorCraft、DeckCraft 执行实际原生操作，OpenDesign 提供锁定版本的设计资源。

本版调用 Windows x64 的 PhotoCraft 0.18.0、VectorCraft 0.19.0、DeckCraft 0.13.1 CLI/MCP。运行时和启动器的 SHA-256 在 runtime-lock.json。OpenDesign 固定提交 12d970eacc8971150e3c76470d2a9afe16dc2ed1，五套 default/editorial/corporate/clean/bold 原始资源和36个文件按 resources/open-design/lock.json 校验。

历史样本中，使用已有 CLIProxyAPI 的 gemini-3.1-flash-image 成功进行了图片请求；当时 OpenRouter 原连接返回 402、没有可用额度。上述结果不代表当前账户状态或本次新增适配已验证。本次续接没有调用图片服务。代码不会自动充值或在失败后悄悄换服务重试；后台任务中断会记录状态并保留已完成候选，不自动重复可能计费的请求。image_start 只表示接收任务，需查询 image_status；停止聊天不等于撤回已经提交的图片任务，图片任务有单独取消入口。

局部重绘采用“图片参考生成＋精确原生蒙版合成”，不声称供应商提供了原生 hard-mask 接口。服务收到原图、蒙版参考和需求；插件将结果限制在实际蒙版内，保留羽化 alpha，区域外严格检查。区域内的生成质量仍取决于所选模型。未合并的共同画布调整、翻转或亮度蒙版会明确拒绝此路径；请先处理到原生源。局部重绘/精确像素选区目前最多8MP，参考图传输合计16MB。

# OpenDesign 固定网页模板导入

图片海报、演示及其他固定 OpenDesign 网页源可通过网页工作区资源面板，或 `designcraft_html` 的 `from_resource` 选择实际固定包和 HTML 入口导入。它复制的是原包真实文件；示例中可能包含演示文字、占位内容、外链或上游脚本，不能当成用户已完成的设计。文件超过预算、符号链接、不可移植名称及大小写冲突会列入遗漏；入口若被排除或整体超预算则拒绝。若选中范围包含 Git LFS 指针，直接拒绝，不把指针当成图片、字体或网页文件。外部仓库已保存原包的 LFS 可选获取仍使用另一条 `from_external` 路径。

工具入口使用 `operationKey` 或当前工具调用身份，网页面板使用稳定操作身份。相同身份再次请求时先核对初始来源并返回已有网页，保留用户后续编辑；`resource_status` 或面板“核对上次网页”只读取该身份的保存状态。面板的“继续同一导入”由用户显式触发，不会自动创建第二份。旧版直接调用网页资源接口且不提供操作身份时仍保留原有随机创建行为。

来源版本 3 在项目中不可变保存导入时的实际 OpenDesign 索引、锁文件和根许可；项目包用这些快照离线重算仓库、版本、包、入口、实际选择和遗漏摘要，并逐一将初始文件与 Git blob、大小及保存摘要对照。快照来自导入时的插件文件，不构成上游签名或版权证明。后续版本的编辑内容保留，但原始来源记录不得改变。版本 2 按当前插件固定索引核对，未来索引更换后可能需要原插件版本；更早无版本标记的历史网页仍按原有规则处理，不因此声称其初始文件已重新核验。其他独立资源依赖可能仍需原插件版本。

主机不执行资源包脚本；网页预览仍使用既有隔离 iframe 和 CSP，预览中的脚本可能运行。外链、CDN、字体、视觉保真、项目包和 HTML 到 PPTX 转换效果均需后续实际验证。本次只编写代码和静态检查，没有下载模板、打开网页或做功能/UI/项目包测试。

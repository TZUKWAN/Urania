# OpenDesign 参考产品电商图工作流（代码阶段）

本工作流依据固定 OpenDesign 版本 `12d970eacc8971150e3c76470d2a9afe16dc2ed1` 的 `skills/ecommerce-image-workflow/SKILL.md`，通过当前 DSH 会话中的 `designcraft_ecommerce` 和专业图片工作区“电商产品图”入口接入。它复用已配置的图片服务与 PhotoCraft 候选，不执行从外部下载的脚本，也不创建第二个对话或代理。

先在图片工作区添加 1 至 4 张实际 PNG/JPEG 产品参考图，选择可接受参考图的图片服务与模型，填写产品名称、需要保留的产品身份细节和已知卖点；场景要求可选。`plan` 读取实际模型目录，将参考文件复制为带摘要的项目原件，记录服务连接摘要，并建立主图、卖点图、场景图三个稳定槽位。模型目录若未声明目标画幅，画幅仅作为构图要求加入提示词，不发送未经声明的参数；实际图片尺寸以服务结果为准。图片模型能力可能来自服务声明或现有适配器的明确标注推断，不代表该账户一定可用。

每个槽位只有在用户选择生成时才通过现有图片服务发出请求。参考图字节和服务连接摘要在发送前核对；源文件或连接发生变化时停止发送。`status` 查看实际图片任务，返回候选不能代替产品保真审核。已有同一槽位任务时不会自动重复，`cancel_slot` 只停止本地等待，服务端可能仍在处理或计费。完整的计划临时候选可用 `recover_plan` 恢复，不会发起生成。

只有三个槽位都有真实完成的候选后，`finalize` 才把实际参考图、选定候选预览、`image-manifest.json` 和 `ecommerce-gallery.html` 保存为独立版本化网页源，可在网页设计列表中查看或导出。清单保留任务、候选、提示词、请求画幅、实际尺寸和摘要；已有画廊或后续人工编辑不会被静默覆盖。项目包核对计划、参考图、任务签名、候选、画廊与清单的实际关系。参考图单张最多 8 MiB、传输总量最多 16 MiB；画廊图片总量最多 22 MiB，超限时保留已有原件和任务。

模型可能改变产品外形、标签、材质或比例；代码不能保证产品忠实度，也不证明平台规则、尺寸、宣传文案或其他声明合规。用户需要核对实际作品。网络中断后远端可能已经产生费用或结果，不能把本地入队或停止当作远端完成/取消。

本轮只编写代码并做静态检查；没有查询图片模型目录、发送图片、调用生成服务、运行界面/功能/恢复/项目包验证，未操作或重启用户 DSH。来源原文保存在项目的固定 OpenDesign 缓存；本实现按照 DSH 的现有图片调度接口适配，不声称运行了上游 CLI 脚本。

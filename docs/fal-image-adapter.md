# fal 图片与队列适配（代码已写入，尚未功能验证）

DesignCraft 可从 DSH 凭据引用 `FAL_KEY` 发现 fal 连接，也可配置使用 `protocol: fal`、官方 `https://api.fal.ai/v1` 和对应的凭据引用。凭据只在宿主侧解析，不写入前端、项目或任务记录。没有凭据时不列出该连接。

代码按官方模型目录中实际返回的 OpenAPI 输入和输出结构筛选图片模型；只传递可以明确对应的提示词和图片字段。为了限制单次候选的结果数量，数组输出要求接口声明可设置 `num_images=1` 或限定单张；其他模型暂不列出。目录按类别分批读取，有数量上限时会显示不完整提示；它不代表 fal 全部模型，也不代表账户有权使用所列模型。

图片请求由 fal 队列受理后，任务 ID、所用模型、连接引用和服务真实状态记录在项目中，不记录凭据或媒体签名链接。停止本地等待不会自动取消远端；用户可以对已获得任务 ID 的中断任务取回原结果，或先停止本地等待后明确请求远端取消。正在运行的任务收到取消信号后仍可能完成或计费；请求发出后未拿到 ID 的情况仍须由用户核对服务端，不自动重发。分批生成中断时，只取回已提交的当前请求，不自动提交剩余方案。

当前仅为图片生成及支持多张参考图的选区合成编写适配；不宣称覆盖 fal 训练、视频、音频、实时、三维或视觉分析等其他工作流。服务端输出域名不在受限来源内、接口描述不兼容、媒体已过期或内容不匹配时会报告失败。

本次没有请求 fal 模型目录、生成服务或队列接口，没有运行功能、界面或端到端验证。协议依据：[模型目录](https://fal.ai/docs/platform-apis/v1/models)、[队列接口](https://fal.ai/docs/documentation/model-apis/inference/queue)、[模型 OpenAPI 例](https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=fal-ai/flux/dev)、[文件输入](https://fal.ai/models/fal-ai/uso/api)。

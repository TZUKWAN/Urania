# 授权条件单列

本清单与“代码未实现”“来源资料不足”“暂缓功能验证”分开。机器其他位置的服务和用户账号状态未检查，不能从当前进程环境缺失推断用户没有账号。未读取凭据值或调用服务验证。

当前没有拿到可用的 **OpenDesign 原版图库 run/project 授权上下文**：原版 OD daemon 地址、真实项目/run、该上下文签发的短期工具令牌，以及上游要求的 Vela 登录/项目权限。不能用 DSH 工作区路径或自造令牌替代。原版接入仍未完成；DesignCraft 的 Commons 公共搜图是另一条能力，不依赖此授权。

用户已配置的图片生成服务和可选 MCP 连接，其当前权限、额度和可用性尚未检查；代码继续推进，实际调用等用户通知。旧 Kimi 429 只作为历史记录，不能据此断定当前仍限额。Figma 等可选连接不是 DesignCraft 核心功能的前提。

这些条件不阻止源码/依赖审计、主题和中文控件代码、固定公共资源读取、Commons 接入代码、原生源/项目包、版本装配和本地交付打包。

历史证据缺档、预构建转换器的精确来源证明、未运行的 UI/功能验证以及额外上游视频/浏览器脚本未适配，都不称为“缺授权”。逐项机器可读记录在 authorization-requirements.json。

# 设计计划手动创建与编辑

当前设计工作区的“设计计划”面板提供“新建计划”和已发布版本的“编辑此版本”。用户填写实际名称、简报和计划后明确保存；新计划使用稳定操作身份，已有计划以所选基础版本做比较并保存，冲突时不会覆盖其他版本。编辑时保留该基础版本的原有来源引用；“另存为新计划”保留文字并创建独立计划，不自动复制原计划来源。

编辑内容先写入当前浏览器本地 IndexedDB 草稿，使用令牌比较避免覆盖另一窗口的草稿；输入间隔短暂合并写入，最近一次输入在持久化前可能仅存于当前窗口内存。若本地存储不可用或发生冲突，界面保留内存应急副本并提示，不把保存结果冒称已确认。可恢复或明确放弃所选草稿；若存在另一份不同草稿，不会自动删除。关闭编辑会保留本地草稿；本地草稿不包含在项目包中。

提交响应丢失时草稿会保留，新计划可用同一操作身份重试，修改已有计划可用同一基础版本重试；成功后仅在内容一致且草稿令牌未被其他窗口改变时清除本地草稿。更晚的输入保持为草稿。此路径尚未进行功能、界面、冲突恢复、持久化或项目包验证；保存计划不代表已生成设计或验证视觉效果。

同一 DSH 对话中的 `designcraft_plan` 可以通过 `directorResources` 明确引用当前插件固定的 creative-director 包内文件。代码在保存前检查原文件摘要并登记包来源；历史恢复和项目包核对文件身份，工作区显示文件名。此声明不能证明模型实际阅读或遵循了文件，调用方应先读取真实内容；不自动执行包内脚本。项目包携带固定原包、许可和署名，但切换到使用不同固定版本的插件后，旧版本的读取与迁移尚无通用支持。此路径尚未进行功能、界面、恢复或项目包验证。

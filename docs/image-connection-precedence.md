# 图片服务连接的配置顺序

插件先读取 `imageConnections`，再为缺少对应 ID 的内置服务添加默认连接。DSH 设置中读取到的同名 provider 沿用现有规则覆盖前面的连接；最终仍需通过宿主凭据服务解析对应引用，不能解析的连接不会列入可用列表。

对 `https://openrouter.ai` 官方主机，未明确写协议时按 OpenRouter 协议识别。其他兼容代理应明确配置其协议与凭据引用；是否支持特定图片模型和参数以实际目录及服务响应为准。

OpenRouter 模型目录中完整有效的 `input_references` 数量范围会用于参考图选择与发送前检查；该字段为模型级各提供方能力的并集，具体路由和返回结果仍以服务为准。无效范围不会被当作可用参考能力；没有数量范围的其他描述符保留原有处理。工作区单次最多四张用户参考图，选区重绘还会使用两张内部参考图。

此调整仅完成源码和静态检查，尚未读取实际账户模型目录或验证连接优先级的运行行为。
